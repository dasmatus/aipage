# User Guide

AIPage adds an AI sidebar to EduPage: chat with Ollama Cloud, OpenRouter, ChatGPT / OpenAI, Claude (Anthropic), Claude Code or a local LM Studio / Ollama, scan the page into the chat, search the web and generate images without leaving EduPage.

1. **[Installation](installation.md)**: install a release (or a nightly) in Chrome / Brave, Firefox or Safari.
2. **[AI Providers](providers.md)**: pick an AI backend, add its API key and start chatting.
3. **[Updates](updates.md)**: update channels, the update check and the self-updating sidebar UI.
4. **[Hosted UI](hosted-ui.md)**: the auto-updating sidebar served from Vercel, its fallback and its security model.
5. **[Anti-Cheat Protection](anti-cheat.md)**: what the extension does while a test is running.
6. **[Privacy & Security](privacy.md)**: where your keys and conversations go.
7. **[Troubleshooting](troubleshooting.md)**: common problems and fixes.
