Setup Required

Choose your preferred AI provider and configure your API key.

How to get your Gemini API key:

  1. Visit Google AI Studio
  2. Sign in with your Google account
  3. Click "Get API Key" or "Create API Key"
  4. Copy the generated key (starts with AIzaSy...)
  5. Paste it below and click "Save Key"

⚠️ Your API key is stored locally and securely in your browser.

How to get your OpenAI API key:

  1. Visit OpenAI Platform
  2. Sign in or create an account
  3. Click "Create new secret key"
  4. Copy the generated key (starts with sk-...)
  5. Paste it below and click "Save Key"

⚠️ OpenAI API usage is billed based on tokens. Check pricing at openai.com/pricing

How to get your Claude API key:

  1. Visit Anthropic Console
  2. Sign in or create an account
  3. Navigate to API Keys section
  4. Click "Create Key"
  5. Copy the generated key (starts with sk-ant-...)
  6. Paste it below and click "Save Key"

⚠️ Claude API requires a paid account. Check pricing at anthropic.com/pricing

How to get your Mistral API key:

  1. Visit Mistral Console
  2. Sign in or create an account
  3. Navigate to API Keys
  4. Click "Create new key"
  5. Copy the generated key
  6. Paste it below and click "Save Key"

⚠️ Mistral API usage is billed based on tokens. Check pricing at mistral.ai/pricing

How to use LM Studio:

  1. Open LM Studio and start the "Local Inference Server" (port 1234 by default)
  2. Ensure a model is loaded in LM Studio
  3. Enter the Base URL below (default: http://localhost:1234/v1)

⚠️ Running models locally requires significant hardware resources.

How to use Ollama:

  1. Install and run Ollama on your machine
  2. Download a model (e.g., `ollama run llama3`)
  3. Enter the Base URL below (default: http://localhost:11434)

⚠️ Ensure Ollama is listening on the provided address.

Your key is stored locally and never shared.
