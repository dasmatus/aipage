🤖 EduPage AI Sidebar

Multi-browser extension bringing AI assistance to EduPage

Chrome Firefox Safari

Features

🌐

Multi-Browser Support

Works seamlessly on Chrome, Firefox, and Safari

🤖

Multiple AI Providers

Support for Gemini, ChatGPT, Claude, Mistral, and local models

🛡️

Anti-Cheat Protection

Automatic blocking of tab switch and copy-paste detection

🔒

Privacy First

API keys stored locally, no data collection

Quick Start

1

Install Dependencies

bun install
2

Build for Your Browser

bun run build:chrome
bun run build:firefox
bun run build:safari
3

Load Extension

Follow browser-specific loading instructions in the User Guide
